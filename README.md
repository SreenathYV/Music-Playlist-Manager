# Music Playlist Manager Using Doubly Linked List

An interactive C++ and Web-based Music Playlist Manager implemented using a **Doubly Linked List** data structure.

---

## 📌 Features

- **Doubly Linked List Architecture**: Bidirectional traversal allowing seamless `Next Song` and `Previous Song` navigation.
- **Playlist Operations**:
  - Add songs at beginning, end, or specific position
  - Delete songs by title or position
  - Search songs by title or artist
  - Shuffle playlist & repeat mode
  - Display playlist forwards and backwards
  - Show currently playing song with duration tracking
- **Interactive Web Interface**: Visual demo and audio player simulation (`index.html`).
- **Comprehensive Documentation**: Complete project report with complexity analysis and implementation details.

---

## 🛠️ Tech Stack

- **Core**: C++ (Standard Template Library / Custom Data Structures)
- **Visualizer**: HTML5, CSS3, JavaScript
- **Data Structure**: Doubly Linked List (`prev`, `data`, `next` pointers)

---

## 🚀 How to Run

### C++ Console Application

1. **Compile**:
   ```bash
   g++ playlist.cpp -o playlist.exe
   ```

2. **Run**:
   ```bash
   ./playlist.exe
   ```

### Web Visualizer

Open `index.html` in any modern web browser to interact with the visual playlist manager.
